# Webhjerte Growth

Дашборд для контролю залучення клієнтів Webhjerte: скільки витрачено, скільки отримано, звідки трафік, CTR, скільки холодних листів надіслано і що з цього стало клієнтами.

Це статичний сайт без збірки (`index.html` + `assets/`) плюс одна серверна функція для синхронізації (`api/data.js`), він працює на телефоні й на десктопі, а на iPhone/Android його можна додати на головний екран.

## Що вміє

- **Огляд**: KPI за обраний період (витрати, дохід, прибуток / ROI / ROAS, клієнти, ліди, кліки, CTR, листи) порівняно з попереднім таким самим періодом. Також графік «витрати vs дохід», воронка «покази → кліки → ліди → зустрічі → клієнти», блок холодних листів із денною ціллю й серією днів, ліди по каналах, цілі місяця і таблиця ефективності каналів із сортуванням (CTR, CPC, CPL, CAC, ROAS…).
- **Канали**: картки по кожному каналу з ключовими метриками й динамікою. За замовчуванням є Google Ads, Meta Ads, Cold mail, LinkedIn, Instagram і Facebook пости. Можна додати свої канали (TikTok, SEO, рекомендації…).
- **Журнал**: усі записи, які ви внесли вручну, згруповані по днях, із пошуком і фільтром за каналом.
- **Клієнти**: ліди й угоди зі статусами *Лід → Зустріч → Пропозиція → Клієнт / Втрачено*. Угода зі статусом «Клієнт» рахується як дохід каналу на дату угоди.
- **Налаштування**: назва, валюта, фірмовий колір, світла або темна тема, цілі (бюджет, дохід, ліди на місяць, листи на день), бекап і відновлення JSON, імпорт і експорт CSV, демо-дані.

## Як вносити дані

Натисніть **+** (на телефоні це кнопка в центрі нижнього меню; на комп'ютері — клавіша `N`), оберіть канал, і форма покаже лише потрібні поля:

| Тип каналу | Поля |
|---|---|
| Платна реклама | витрати, покази, кліки, ліди, зустрічі |
| Холодні листи | листів надіслано, відповідей, ліди, зустрічі, витрати |
| Органічні пости | постів, охоплення, кліки, ліди, зустрічі, витрати |

### Імпорт CSV

```
date,channel,spend,impressions,clicks,emails,replies,posts,leads,meetings,note
2026-10-17,Google Ads,350,4200,96,,,,4,1,Пошукова кампанія
2026-10-17,Cold mail,,,,40,3,,1,1,Ресторани Орхус
```

- Підходить роздільник `,` або `;`.
- Дата у форматі `YYYY-MM-DD` або `DD.MM.YYYY`.
- Десяткову кому розпізнано.
- Заголовки можна писати українською (`дата`, `канал`, `витрати`, `кліки`, `покази`, `ліди`…).
- Невідомі канали створяться автоматично.

## Де зберігаються дані

- **Локально.** Копія даних завжди лежить у браузері (`localStorage`), тому дашборд працює навіть без інтернету.
- **У хмарі.** Якщо в «Налаштування → Синхронізація» підключено синхронізацію, дані зберігаються у вашій MySQL на Aiven через API `api/data.js`, який працює на Vercel як серверна функція. Пароль від бази лежить тільки на сервері, у браузер він не потрапляє.

Як працює синхронізація:
- Усі дані зберігаються як один JSON-документ у таблиці `webhjerte_state`. Таблиця створюється автоматично під час першого запиту.
- Кожен пристрій надсилає зміни через секунду після редагування. Свіжі дані він підтягує, коли ви відкриваєте вкладку, і далі раз на хвилину.
- Якщо два пристрої змінили дані одночасно, записи зливаються за `id` і часом зміни. Видалення теж синхронізуються.
- Зміни, зроблені офлайн, відправляться, щойно з'явиться інтернет.

### Налаштування (один раз)

1. **Aiven.** Відкрийте MySQL-сервіс і скопіюйте *Service URI* (`mysql://avnadmin:…@…aivencloud.com:12345/defaultdb?ssl-mode=REQUIRED`).
2. **Vercel.** Відкрийте проєкт, прив'язаний до цього репозиторію, і перейдіть у Settings → Environment Variables. Додайте:
   - `DATABASE_URL` — Service URI з Aiven;
   - `APP_PASSWORD` — будь-який довгий пароль, ним дашборд входить у синхронізацію;
   - `MYSQL_CA_CERT` (необов'язково) — вміст *CA certificate* з Aiven, щоб перевіряти сертифікат сервера. Без нього з'єднання все одно шифрується.
   
   Після цього зробіть Redeploy.
3. **Дашборд.** На кожному пристрої відкрийте Налаштування → Синхронізація, введіть той самий пароль і натисніть «Підключити».
   - Адреса API підставляється сама: `/api/data` на Vercel або `https://shawarma-five.vercel.app/api/data` на GitHub Pages.

## Запуск

- Локально: відкрийте `index.html` або запустіть `python3 -m http.server` і перейдіть на `http://localhost:8000`.
- Vercel: сайт разом із API синхронізації (`vercel.json`, `api/data.js`).
- GitHub Pages: https://ivan3750.github.io/shawarma/ — кожен пуш у `main` автоматично публікується (workflow `.github/workflows/pages.yml` копіює `main` у гілку `gh-pages`, яку роздає GitHub Pages).

Фірмовий колір задано змінною `--brand` в `assets/styles.css`, а змінити його можна й в інтерфейсі (Налаштування → Фірмовий колір).
